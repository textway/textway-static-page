Textway API 이용약관

제1장 총칙

제1조 (목적)

본 약관은 주식회사 텍스트웨이(이하 "회사")가 제공하는 Textway API 서비스(이하 "서비스")의 이용조건 및 절차, 회사와 회원 간의 권리·의무 및 책임사항 등을 규정함을 목적으로 함.

제2조 (정의)

  1. "Textway API"란 비정형 텍스트를 벡터화 및 구조화하고, RAG 기반 LLM 응답까지 가능한 텍스트 인프라 API를 의미함.
  2. "회원"이란 본 약관에 동의하고, 회사의 API 서비스를 이용하는 자를 의미함.
  3. "API 입력 데이터"란 회원이 서비스에 입력하는 텍스트, 메타데이터 등 일체의 데이터를 말함.
  4. "API 출력 데이터"란 입력에 대해 회사 API가 생성한 태그, 박스 구조, 요약, 응답 등 결과물을 말함.

제2장 이용계약 및 관리

제3조 (계약의 성립)

  1. 회원은 회사가 정한 절차에 따라 서비스 이용을 신청하고, 회사의 승낙이 있는 경우 계약이 성립됨.
  2. 회사는 부정확한 정보 입력, 타인의 명의 도용, 서비스 목적 외 이용 등 합리적인 사유가 있는 경우 신청을 거절할 수 있음.

제4조 (계정 및 인증)

  1. API 사용은 발급된 인증 토큰(Token)을 통해 이뤄지며, 회원은 이를 안전하게 관리할 책임이 있음.
  2. 인증 토큰을 타인과 공유하거나 유출할 경우, 회사는 해당 계정을 정지시킬 수 있음.

제3장 서비스의 제공 및 제한

제5조 (서비스 내용)

  1. Textway API는 문서 임베딩, 태그 자동 추천, 박스 구조화, RAG 검색 응답 등을 포함함.
  2. 서비스는 회원의 개발 환경 내에서 API 요청을 통해 호출 가능함.

제6조 (서비스의 제공 범위)

  1. API는 실시간 또는 비동기 방식으로 제공되며, 회사는 처리 가능 건수 및 속도 등을 기준으로 요금제를 운영함.
  2. 서비스 사용량, 속도 제한, 요금 등의 내용은 별도 안내에 따름.

제7조 (API 데이터 처리 원칙)

  1. 회사는 API 입력 데이터 및 출력 데이터를 저장하지 않으며, 모델 학습이나 개선 목적에도 활용하지 않음.
  2. 단, 비동기 API의 경우 결과 제공을 위해 입력 데이터는 최대 3일, 출력 데이터는 최대 30일 보관될 수 있음.
  3. 위 보관은 회원의 명시적 요청에 의해 삭제 가능함.

제8조 (지식정보 생성물의 권리)

  1. 회원은 API를 통해 생성된 태그, 박스, 요약 등의 결과물을 비독점적으로 사용할 수 있음.
  2. 다만, 결과물의 정확성과 신뢰도에 대해서는 회사가 보증하지 않으며, 회원은 이를 참고자료로만 활용해야 함.

제9조 (서비스 제한 및 중단)

회사는 다음 각 호에 해당하는 경우 API 사용을 제한하거나 중단할 수 있음:

  • 인증 정보의 유출 또는 타인에 의한 도용
  • DDoS, 자동 요청 도구 등 비정상적 접근 시도
  • 모델 반출, 역설계 등의 행위 발생

제4장 요금 및 환불

제10조 (요금 부과)

  1. Textway API는 사용량에 따라 후불 또는 선불 방식으로 요금이 부과됨.
  2. 요금제, 청구 주기, 사용 단위 등은 별도 안내 페이지에 따름.

제11조 (환불 및 청약철회)

  1. 미사용 시 결제일로부터 7일 이내 환불 가능함.
  2. 일부 사용된 경우 사용분 차감 후 잔액 환불 가능함.
  3. 환불 요청은 고객지원 채널을 통해 접수되며, 7영업일 이내 처리함.

제5장 기타

제12조 (지적재산권)

  1. API 및 결과물의 구조, 알고리즘, 데이터베이스는 회사에 귀속되며, 무단 복제·배포·전송 등을 금함.
  2. 회원은 출력 데이터의 자체적 저장·활용은 가능하나, 이를 모델 학습이나 경쟁 서비스 구축에 사용할 수 없음.

제13조 (면책 및 분쟁 해결)

  1. 회사는 API 사용 중 발생한 법적·윤리적 책임, 데이터 손실, 해석 오류 등에 대해 책임지지 않음.
  2. 분쟁 발생 시 회사 본점 소재지를 관할하는 법원을 제1심 관할 법원으로 함.
