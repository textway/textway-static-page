개인정보 처리방침

시행일: 2025년 6월 20일

본 개인정보처리방침은 주식회사 텍스트웨이(이하 "회사")가 제공하는 Textway API 서비스(이하 "서비스") 및 회사 홈페이지를 이용하는 회원·이용자의 개인정보를 어떻게 수집·이용·보관·파기하는지를 명확히 안내함을 목적으로 함.

제1조 (개인정보 수집 항목 및 수집 방법)

회사는 서비스 제공에 필요한 최소한의 개인정보만을 수집함.

수집 항목

구분항목
API 서비스 (필수)이메일, API 토큰, IP 주소, 접속 로그
API 서비스 (선택)조직명, 담당자명, 전화번호
홈페이지 문의하기 (필수)성함 또는 회사명, 이메일, 문의 내용

수집 방법

  • 홈페이지 회원가입 및 서비스 이용 중 입력
  • 홈페이지 문의하기 폼 입력
  • API 사용 로그 및 통계 자동 수집

제2조 (개인정보의 이용 목적)

  • 서비스 제공 및 운영 관리 (사용량 확인, 요금 청구 등)
  • 기술지원, 장애 대응, 고객 응대
  • 도입 상담 및 문의 처리
  • 계약 이행 및 의무사항 이행
  • 서비스 개선을 위한 통계 분석 (익명 처리 후 활용)

제3조 (개인정보 보유 및 이용기간)

회원 탈퇴 시 즉시 파기함. 단, 관련 법령에 따라 일정기간 보관이 필요한 정보는 예외.

상법 및 전자상거래법 등 관계법령에 따라 보존할 필요가 있는 경우 다음과 같이 보관함:

보관 항목보유 기간
계약 또는 청약철회 기록5년
대금 결제 및 재화 공급 기록5년
소비자 불만 또는 분쟁처리 기록3년
접속 로그 및 IP 정보3개월
홈페이지 문의하기로 수집된 정보문의 처리 완료 후 1년

제4조 (개인정보의 제3자 제공)

회사는 원칙적으로 개인정보를 외부에 제공하지 않음.

다만 다음의 경우에는 예외로 함:

  • 이용자의 사전 동의가 있는 경우
  • 관계 법령에 의거하여 적법하게 요구되는 경우

제5조 (개인정보의 처리 위탁)

회사는 서비스 운영에 필수적인 업무에 대해 다음과 같이 개인정보 처리를 위탁할 수 있음.

  • 클라우드 인프라 제공사: AWS, GCP 등
  • 이메일 발송 시스템: EmailJS 등

※ 위탁 시 수탁사와의 계약을 통해 개인정보 보호 의무를 명확히 규정함.

제6조 (개인정보 보호를 위한 기술적·관리적 조치)

  • 개인정보는 암호화된 채널(SSL)을 통해 전송되며, 안전하게 저장·관리됨.
  • 주요 정보에 대해서는 접근 권한 제한 및 정기적 보안 점검 실시
  • API 인증 정보는 별도 암호화 저장 및 관리

제7조 (개인정보 자동 수집 장치의 설치·운영 및 거부)

회사는 API 사용과 관련하여 서비스 품질 향상을 위해 자동 수집 장치를 운영할 수 있음.

  • 수집항목: 접속 시간, IP, 요청량, 에러 코드 등
  • 목적: 기술 분석 및 과금 기준 확보
  • 이용자는 브라우저 설정을 통해 쿠키 저장을 거부할 수 있음.

제8조 (이용자의 권리와 행사 방법)

  • 회원은 언제든지 본인의 개인정보 열람, 정정, 삭제, 처리정지를 요구할 수 있음.
  • 개인정보 관련 요청은 이메일(info@textway.net)을 통해 접수 가능하며, 7일 이내 처리함.

제9조 (위치정보 처리에 대한 방침)

  • 현재 Textway API는 위치정보를 수집하거나 활용하지 않음.
  • 향후 위치기반 기능이 추가되는 경우, 별도 고지 및 동의 절차를 통해 처리함.

제10조 (개인정보 보호 책임자)

  • 책임자: 유승민
  • 이메일: info@textway.net
